# Экономика информатизации — решение экзаменационной задачи №7

Самостоятельная воспроизводимая оценка эффективности внедрения информационной системы для автоматизации документооборота в государственном учреждении. Модель построена по материалам лекции №8: ROI, NPV, IRR и простой/дисконтированный Payback Period.

## Ключевая идея

Проект сравнивается не только по сумме выгод, но и по времени поступления денежных потоков, налогу на прибыль, амортизации и стоимости первоначальных инвестиций. Рост удовлетворённости граждан учитывается как отдельная неденежная выгода и не включается в базовый cash flow без денежной оценки.

## Что рассчитывается

- инвестиции года 0;
- ежегодные эксплуатационные затраты;
- амортизация оборудования;
- прибыль до и после налога;
- чистые денежные потоки;
- NPV;
- IRR численным методом;
- простой и дисконтированный Payback Period;
- ROI;
- чувствительность NPV к ставке дисконтирования, экономии времени и стоимости разработки;
- минимальная ежегодная экономия времени для NPV = 0 и целевого положительного NPV;
- динамические таблицы, график и текстовые выводы.

## Базовый результат

При исходных данных инвестиции составляют 55 млн руб., денежные выгоды — 15 млн руб./год, эксплуатационные затраты — 9 млн руб./год, а чистый денежный поток после налога — 5,4 млн руб./год.

Базовые показатели: NPV около −34,53 млн руб., ROI около −25,0%, IRR около −19,8%; простой и дисконтированный срок окупаемости не достигаются на горизонте 5 лет. Для NPV = 0 требуется ежегодная экономия времени примерно 19,39 млн руб. при прочих неизменных параметрах.

## Как изменить модель

Все параметры редактируются в `data/task_07_efficiency_config.json`. После изменения инвестиций, выгод, затрат, ставки, горизонта или сценариев нужно перезапустить Notebook с начала. Таблицы, график и выводы обновятся автоматически.

## Методические ограничения

Неденежный эффект удовлетворённости граждан не включён в NPV и ROI без денежной оценки. ROI построен по номинальным совокупным выгодам и затратам, а NPV — по дисконтированным потокам. Для окончательного решения также нужны данные пилотного внедрения и оценка рисков проекта.

## Сценарии выхода в прибыль

В JSON есть блок `analysis_targets`. В нём задаются целевые значения NPV для безубыточности и положительного результата. Notebook показывает, какая ежегодная экономия времени необходима при неизменных остальных параметрах. Это один прозрачный сценарий, а не единственный способ улучшения экономики проекта.

В Notebook также приведён расширенный сценарный анализ: однорычаговое влияние экономии времени, первоначальных инвестиций, эксплуатационных затрат и прочих выгод; графики зависимости NPV от каждого фактора; а также комбинированный план достижения NPV = 0 и заданной прибыли.


### Переключатель денежной оценки социальной выгоды

Параметр `modeling_choices.include_non_cash_benefit_in_cash_flow` управляет включением выгоды `annual_benefits.citizen_satisfaction_non_cash` в денежный поток. По умолчанию установлено `false`: социальный эффект показывается отдельно и не влияет на NPV, ROI, IRR и Payback. Если учреждение обосновало денежный эквивалент, необходимо изменить значение на `true`; после этого Notebook автоматически пересчитает все показатели.
