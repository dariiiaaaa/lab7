# Глоссарий задачи №7

**ROI** — относительная отдача от инвестиций: отношение чистого результата к затратам.

**NPV** — чистая приведённая стоимость; разница между приведёнными выгодами и затратами.

**IRR** — внутренняя норма доходности, ставка, при которой NPV равен нулю.

**Payback Period** — простой срок окупаемости первоначальных вложений.

**Дисконтированный Payback** — срок окупаемости с учётом стоимости денег во времени.

**CF** — чистый денежный поток за период.

**PV** — текущая стоимость отдельного будущего денежного потока.

**CAPEX** — капитальные затраты на создание и внедрение системы.

**OPEX** — ежегодные эксплуатационные расходы.

**Амортизация** — бухгалтерское распределение стоимости оборудования по годам; сама по себе не является выплатой денег.

**Налогооблагаемая прибыль** — прибыль после вычета эксплуатационных расходов и амортизации, с которой рассчитывается налог.

**Денежная выгода** — эффект, который можно выразить в рублях и включить в cash flow.

**Неденежная выгода** — полезный результат, для которого в условии нет обоснованного денежного эквивалента.

**Ставка дисконтирования** — ставка приведения будущих потоков к моменту начала проекта.

**Чувствительность** — проверка изменения результата при изменении одного параметра.
